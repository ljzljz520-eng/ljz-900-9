# 连锁药店巡检整改台

零依赖纯前端应用（HTML + CSS + 原生 JS），面向连锁药店的巡检—整改—汇总闭环：

- **督导端**：按门店发起巡检，分类（药品陈列 / 冷藏柜 / 处方药区 / 其他）录入问题、
  拍照或相册上传多张问题图、设定扣分项；一键生成「整批整改码」和「单项整改码」（可打印）。
- **店员端**：微信/相机扫描二维码直接进入整改页（无需登录、无需安装），
  每张问题图对应上传一张整改图，支持重传替换、记录整改人，实时显示进度。
- **老板汇总**：全连锁完成率环、总扣分/待整改扣分、门店排名、
  问题图 ➜ 整改图成对浏览、按门店/状态筛选、打印报表。

## 编号连续性（重点规则）

- 问题条目编号 `#01、#02 …`、问题图编号「问题图 1、2 …」均为**按当前数组顺序实时计算**，
  不入库。删除任意条目或图片后，后续编号自动前移，始终保持连续。
- 删除问题图时，对应位置的整改图一并删除，保证问题/整改始终成对。

## 数据与图片存储

- 业务数据（门店、批次、条目、扣分、整改记录）存 `localStorage`；
- 图片经 Canvas 压缩（最长边 1280px、JPEG 0.82）后以 Blob 存 **IndexedDB**，
  避免大图撑爆 localStorage；启动时自动清理无引用的孤儿图片。
- 全部数据仅保存在当前浏览器，不上传任何服务器。

## 运行

任意静态服务器即可（需 http 访问，手机扫码请用局域网地址）：

```bash
python3 -m http.server 8080
# 电脑：http://localhost:8080
# 手机（同局域网扫码）：http://<电脑IP>:8080
```

首次打开可点首页「载入演示数据」，自动生成 3 家门店、3 个巡检批次
（含 Canvas 绘制的问题图/整改图示意），完整体验全流程；可随时「清空全部数据」。

## 目录

```
index.html        页面骨架
css/styles.css    全部样式（响应式、移动端、打印）
js/qrcode.min.js  本地二维码库（qrcodejs，离线可用）
js/storage.js     IndexedDB 图片库 + localStorage 数据层 + 压缩/CRUD/GC
js/demo.js        Canvas 演示数据生成
js/app.js         路由与三个端的全部界面逻辑
```

## 主要路由（hash）

| 路径 | 角色 |
| --- | --- |
| `#/` | 首页（角色入口 / 演示数据） |
| `#/supervisor` | 督导端：门店管理、批次列表 |
| `#/batch/:id` | 批次详情：录入/删除问题、二维码、归档 |
| `#/fix?b=批次id[&i=条目id]` | 店员扫码整改页 |
| `#/boss` | 老板汇总看板 |

## 完成率口径

按图片口径计算：`已整改图数 / 问题图总数`；同时给出「已整改条目数」辅助参考。
